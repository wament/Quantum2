# Blackjack

A Blackjack game written in C++ using SFML.

![Gameplay Screenshot](docs/screenshots/gameplay.png)

## Features

- Multiple deck shoe
- Blackjack detection
- Dealer AI
- Split hands
- Double down
- Cut card system
- Sprite-based card rendering
- SFML graphics

## Controls

| Key | Action |
|---|---|
| H | Hit |
| S | Stand |
| D | Double Down |
| P | Split |
| R | New Round |

## Requirements

- C++17 compiler
- SFML 2.x
